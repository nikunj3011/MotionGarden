# Mathematical music

The React app now includes a Music tab in Works and a top Music link. Three original procedural pieces use Web Audio oscillators, envelopes and a dynamics compressor: Ambient (slow pentatonic chords), Polyrhythm (Euclidean pulses with synthesized percussion) and Arpeggio (Fibonacci-derived scale degrees). There is no AI model, sampled recording, microphone permission, audio download or external music service. Notes are scheduled ahead against AudioContext.currentTime, not played directly from unreliable UI timers.

A random piece and seed are chosen for the session. Sound is enabled by default and attempts to start on every load/refresh, unless previously muted. Browsers can block audible autoplay: in that case the UI stays at Ready to listen / Tap for sound and retries on interaction. Autoplay is never falsely reported as playing. The top control can mute/unmute, and the music player can stop playback, change seed or choose a random piece. A previous mute choice persists in browser localStorage. Sound continues across React routes, while tab backgrounding suspends it. Stopping does not automatically restart on later unrelated clicks. The music player canvas uses the same seed and the actual audio analyser energy to shape its curves; reduced motion suppresses animated deformation.

The main page has a small real-time analyser-bar signature just above MOTION. It shows the current title and status. Clicking the signature opens that exact music viewer without replacing or restarting the soundtrack. Its adjacent shuffle button chooses a different music piece. Surprise me chooses a different artwork in the current gallery filter; the expanded artwork player also offers another-artwork selection. The player remounts per artwork ID so renderer readiness and parameters reset correctly.

**React to music** is enabled by default, with a toggle beside the main visualizer and in the expanded player's controls. The choice persists locally. The React host reads real analyser bins, separates bass/mid/treble by frequency, smooths the values, and sends a validated SET_AUDIO message to the shared renderer at about 16 Hz. Bass modulates particle speed/sculpture scale, mids add flow curvature/rotation changes, and highs affect line weight/subtle sculpture detail. Base slider values and presets are not overwritten. Turning the toggle off, muting/stopping audio, backgrounding, or reduced-motion preference sends neutral values. Paused artworks stay paused. This follows the current synthesized soundtrack, including when it changes; it does not access a microphone or external device audio.

The main page also shows a miniature music viewer to the left of MOTION, using the same circular visualizer component as the full music page. It includes the current title/style, Play/Stop, New seed and a viewer link. The music-reaction button now displays a waveform icon and the visible label **Reacts to music**, plus On/Off, in both desktop and mobile layouts. A direct visit to a music page chooses that piece before attempting autoplay.

Latest UI: one unified soundtrack card is positioned above MOTION and reused inside the expanded artwork controls. It groups the circular art, current track/style/tempo, real spectrum bars and viewer links. New-seed, shuffle, mute and Reacts to music controls share one row; the compact card no longer has a stop button. The full dedicated music page retains playback controls. See `docs/adding-art-and-music.md` for the distinction between adding an audio mapping to new artwork and adding music recipes or synthesis styles.

Responsive follow-up: the card remains above MOTION on desktop but sits beside it on mobile. Both themes use a 52% tinted surface with lighter blur so artwork remains visible through the panel. A top-right expand/minimize control changes between the full viewer and a compact track/spectrum/control layout without changing playback. Main and expanded-player panel sizes are remembered separately in browser storage. Mobile compact mode keeps mute and the reaction toggle visible while hiding the larger visualization and secondary actions.

`packages/generative-music` contains the schema, pure note/rhythm functions and synthesis engine. `content/music/v1/index.json` is the shared piece metadata; this initial React release bundles it at build time, so changing it requires a rebuild. The publishing tool includes the music directory. Native music playback and downloads are not implemented.

Tests verify valid metadata, Euclidean pulse counts, equal-tempered frequencies, deterministic in-scale notes, creation of real browser oscillators, non-zero analyser energy, top mute persistence, stopping/suspension, Works discovery and music search. Automated checks verify signal production, not subjective listening quality. Device speakers/headphones and mobile audio interruption behavior still need listening tests before a production release.

White mode now uses the original gold/blue/ivory dark default palette. Dark mode uses near-black surfaces and gold/black/ivory defaults. Existing custom palettes are retained; only old default palettes migrate. Text colors stay unchanged.
