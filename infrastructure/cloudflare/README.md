Host the web `dist/` on Cloudflare Pages. Publish the content directories to R2 using a custom public HTTPS domain; do not use the rate-limited development public bucket URL for production.

The player intentionally executes packages only from its own controlled origin. For split Pages/R2 hosting, configure a Pages/Worker route that proxies `/artworks/*` and `/catalog/*` from your R2 bucket, or publish the complete renderer and its content together on the content origin. Setting a cross-origin catalog URL alone does not authorize cross-origin scripts.

Set `R2_BUCKET=motiongarden-content` and `CONTENT_ORIGIN=https://cdn.example.com/`. Authenticate Wrangler separately. After `npm run build`, run `node tools/publish.mjs plan`, then `node tools/publish.mjs publish`. Uploads stop on error; the catalog commits last. `node tools/publish.mjs rollback REVISION` restores a locally archived index. Retain `releases/` securely between deployments. The CLI is provided but has not been run against a real account.

Use a single publishing job, disable CDN negative caching for publish checks, and purge the catalog after publishing. The public-origin existence check is not an atomic object-store lock. Before a production launch, replace it with S3 conditional writes and durable remote catalog history. Never change a published `v1` file: bump artwork and renderer versions, and evolve contracts to accept that version first. The initial slice only supports `v1`.

Apply CSP to the website response: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data: blob:; connect-src 'self' YOUR_CONTENT_ORIGIN; frame-src 'self'; object-src 'none'; base-uri 'self'; frame-ancestors 'none'. The renderer HTML carries its own stricter policy. Configure `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, and Permissions-Policy disabling camera, microphone, and geolocation.
